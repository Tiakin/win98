# Win98 Theme for Orpheus

A Windows 98 style theme for [Orpheus](https://github.com/Collectif-Pixel/orpheus).

## Preview

Classic Windows 98 aesthetic with blue title bar, gray background, and 3D borders.

## Features

- Classic Windows 98 window style
- Blue title bar with "Music_Player.exe"
- Animated progress bar slider
- Courier New monospace font
- 3D inset borders

## Installation

```bash
orpheus add @roseratugo/win98
orpheus use @roseratugo/win98
```
